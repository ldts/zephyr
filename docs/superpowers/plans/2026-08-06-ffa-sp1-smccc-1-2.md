# FF-A SP-1: SMCCC 1.2 extended-register call layer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an SMCCC 1.2 SMC/HVC call primitive to Zephyr AArch64 that marshals the full x0–x17 register range, as the foundation the FF-A core subsystem (SP-2+) is built on.

**Architecture:** Introduce a new 18-register argument/result struct `arm_smccc_1_2_regs` and two leaf assembly routines `arm_smccc_1_2_smc` / `arm_smccc_1_2_hvc` that load x0–x17 from an input struct, execute the conduit instruction, and store x0–x17 back to a result struct. This is kept entirely separate from the existing 8-register `arm_smccc_res` / `arm_smccc_smc` path so PSCI and the legacy OP-TEE SMC transport are untouched. Gated by a new `CONFIG_ARM_SMCCC_1_2` Kconfig.

**Tech Stack:** Zephyr (AArch64 arch port), GNU assembler (`.S`), Kconfig, CMake, Ztest, `west`/twister on `qemu_cortex_a53`.

## Global Constraints

- Target arch: AArch64 (`arch/arm64`) only. The new symbols must not be built for other arches.
- Do not modify `struct arm_smccc_res`, `arm_smccc_smc`, `arm_smccc_hvc`, or `smccc-call.S`'s existing macro/entry points — the legacy 8-register path stays byte-for-byte behaviourally identical.
- Register order and callee-saved handling per SMCCC 1.2 / DEN0028: load x0/x1 last, use a callee-saved register (x19) to hold the result pointer across the conduit instruction, and save/restore x19.
- `struct arm_smccc_1_2_regs` is a contiguous array of 18 `unsigned long` (`a0`..`a17`), so byte offset of `aN` == `N * 8`. Assembly uses literal offsets; C guards the layout with `BUILD_ASSERT`.
- License header: Apache-2.0, matching the existing files in each directory.
- SMC/HVC are privileged instructions that trap to EL3/EL2 and cannot execute on `native_sim`/host — runtime functional coverage of the ABI lands in SP-2 (first real FF-A user). SP-1 verification is layout correctness + arm64 build/link.

### Task 2: Assembly routines `arm_smccc_1_2_smc` / `arm_smccc_1_2_hvc`

**Files:**
- Modify: `arch/arm64/core/smccc-call.S`

**Interfaces:**
- Consumes: `struct arm_smccc_1_2_regs` layout (contiguous `unsigned long` a0..a17; offset of aN == N*8) from Task 1.
- Produces: linkable global symbols `arm_smccc_1_2_smc`, `arm_smccc_1_2_hvc` with the C signatures from Task 1 (x0 = `args`, x1 = `res`).

- [ ] **Step 1: Add a guarded macro and the two entry points**

Append to `arch/arm64/core/smccc-call.S` (after the existing `arm_smccc_hvc` definition):

```asm
#ifdef CONFIG_ARM_SMCCC_1_2
/*
 * SMCCC v1.2 calling convention: pass and return x0-x17.
 *
 * x0 = const struct arm_smccc_1_2_regs *args
 * x1 = struct arm_smccc_1_2_regs *res
 *
 * struct arm_smccc_1_2_regs is 18 contiguous unsigned longs, so the byte
 * offset of member aN is N*8.
 */
.macro SMCCC_1_2 instr
	/* Preserve res (x1) across the call in callee-saved x19 */
	stp	x1, x19, [sp, #-16]!
	mov	x19, x1

	/* Load x0-x17 from *args; load x0/x1 last since x0 holds args */
	ldp	x16, x17, [x0, #(16 * 8)]
	ldp	x14, x15, [x0, #(14 * 8)]
	ldp	x12, x13, [x0, #(12 * 8)]
	ldp	x10, x11, [x0, #(10 * 8)]
	ldp	x8,  x9,  [x0, #(8 * 8)]
	ldp	x6,  x7,  [x0, #(6 * 8)]
	ldp	x4,  x5,  [x0, #(4 * 8)]
	ldp	x2,  x3,  [x0, #(2 * 8)]
	ldp	x0,  x1,  [x0, #(0 * 8)]

	\instr	#0

	/* Store x0-x17 into *res (held in x19) */
	stp	x0,  x1,  [x19, #(0 * 8)]
	stp	x2,  x3,  [x19, #(2 * 8)]
	stp	x4,  x5,  [x19, #(4 * 8)]
	stp	x6,  x7,  [x19, #(6 * 8)]
	stp	x8,  x9,  [x19, #(8 * 8)]
	stp	x10, x11, [x19, #(10 * 8)]
	stp	x12, x13, [x19, #(12 * 8)]
	stp	x14, x15, [x19, #(14 * 8)]
	stp	x16, x17, [x19, #(16 * 8)]

	ldp	x1, x19, [sp], #16
	ret
.endm

GTEXT(arm_smccc_1_2_smc)
SECTION_FUNC(TEXT, arm_smccc_1_2_smc)
	SMCCC_1_2	smc

GTEXT(arm_smccc_1_2_hvc)
SECTION_FUNC(TEXT, arm_smccc_1_2_hvc)
	SMCCC_1_2	hvc
#endif /* CONFIG_ARM_SMCCC_1_2 */
```

### Task 3: Layout + link verification test

**Files:**
- Create: `tests/arch/arm64/smccc_1_2/CMakeLists.txt`
- Create: `tests/arch/arm64/smccc_1_2/prj.conf`
- Create: `tests/arch/arm64/smccc_1_2/testcase.yaml`
- Create: `tests/arch/arm64/smccc_1_2/src/main.c`

**Interfaces:**
- Consumes: `struct arm_smccc_1_2_regs`, `arm_smccc_1_2_smc`, `arm_smccc_1_2_hvc` (Tasks 1–2).
- Produces: a twister-runnable Ztest suite `arch.arm64.smccc_1_2`.

Rationale for what is tested: the SMC/HVC instructions trap to EL3/EL2 and cannot run on host, and `qemu_cortex_a53` has no FF-A responder, so we do not *invoke* a live secure call here. Instead we verify (a) the struct layout the assembly relies on (`sizeof == 18*8`, `offsetof(aN) == N*8`), and (b) that the symbols are declared with the correct signature and link. Live ABI exercise arrives in SP-2 via `FFA_VERSION` on the OP-TEE-enabled QEMU.

- [ ] **Step 1: Write the failing test**

`tests/arch/arm64/smccc_1_2/src/main.c`:

```c
/*
 * Copyright 2026 Qualcomm Innovation Center, Inc.
 *
 * SPDX-License-Identifier: Apache-2.0
 */

#include <zephyr/ztest.h>
#include <zephyr/arch/arm64/arm-smccc.h>
#include <stddef.h>

/* The assembly in smccc-call.S assumes aN is at byte offset N*8. */
ZTEST(smccc_1_2, test_regs_layout)
{
	zassert_equal(sizeof(struct arm_smccc_1_2_regs), 18UL * sizeof(unsigned long),
		      "arm_smccc_1_2_regs must be 18 contiguous longs");
	zassert_equal(offsetof(struct arm_smccc_1_2_regs, a0), 0 * 8, "a0 offset");
	zassert_equal(offsetof(struct arm_smccc_1_2_regs, a2), 2 * 8, "a2 offset");
	zassert_equal(offsetof(struct arm_smccc_1_2_regs, a8), 8 * 8, "a8 offset");
	zassert_equal(offsetof(struct arm_smccc_1_2_regs, a16), 16 * 8, "a16 offset");
	zassert_equal(offsetof(struct arm_smccc_1_2_regs, a17), 17 * 8, "a17 offset");
}

/*
 * Reference both symbols so the test link-fails until they are implemented.
 * Guarded so it is never actually executed (no FF-A responder on this board).
 */
ZTEST(smccc_1_2, test_symbols_link)
{
	void (*smc_fn)(const struct arm_smccc_1_2_regs *, struct arm_smccc_1_2_regs *) =
		arm_smccc_1_2_smc;
	void (*hvc_fn)(const struct arm_smccc_1_2_regs *, struct arm_smccc_1_2_regs *) =
		arm_smccc_1_2_hvc;

	zassert_not_null((void *)smc_fn, "smc symbol");
	zassert_not_null((void *)hvc_fn, "hvc symbol");
}

ZTEST_SUITE(smccc_1_2, NULL, NULL, NULL, NULL, NULL);
```
